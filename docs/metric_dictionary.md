# Metric Dictionary

| Metric | Definition |
| --- | --- |
| Active students | Count of students with `status = Active`. |
| Attendance rate | Attended attendance records divided by all attendance records. |
| Session delivery rate | Delivered sessions divided by planned sessions. |
| Assessment completion rate | Active students with both pre and post assessments divided by active students. |
| Facilitator visit completion rate | Completed visits divided by planned visits. |
| Late submission rate | Attendance records submitted more than two days after the session. |
| High-risk students | Students with baseline risk level of `High`. |
| Average delivery quality score | Mean facilitator/session quality score for delivered sessions. |
| Average satisfaction score | Mean student survey satisfaction score. |
| Open interventions | Program follow-up records with status `Open`, `In Progress`, or `Overdue`. |
| At-risk school | School with weak attendance or weak session delivery. |
| Data quality issues | Records that failed validation, relationship, or duplicate checks. |
